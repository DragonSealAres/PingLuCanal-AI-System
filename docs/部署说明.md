# 部署说明

## 环境要求

- JDK 17
- Maven 3.8+
- Node.js 18+
- MySQL 8
- 现代浏览器，建议 Chrome 或 Edge

## 环境变量

复制 `.env.example`，在本机创建实际环境配置。不要把真实密钥提交到仓库。

后端必需：

```bash
MYSQL_ROOT_PASSWORD=your_mysql_password_here
AI_API_KEY=your_ai_api_key_here
AI_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
AI_MODEL=qwen3-vl-plus
AI_EMBEDDING_MODEL=text-embedding-v4
```

PC端必需：

```bash
VITE_API_BASE_URL=http://localhost:8080
VITE_AMAP_KEY=your_amap_key_here
VITE_AMAP_SECURITY_JS_CODE=your_security_js_code_here
```

移动端必需：

```bash
VITE_API_BASE_URL=http://localhost:8080
```

## 数据库初始化

```bash
mysql -u root -p < docs/sql/schema.sql
```

如需课程演示数据：

```bash
mysql -u root -p < docs/sql/demo_data.sql
```

## 后端启动

Windows本地开发推荐：

```powershell
cd backend
.\start-backend-dev.ps1
```

通用方式：

```bash
cd backend
mvn spring-boot:run
```

启动后访问：

- 后端接口：`http://localhost:8080`
- Swagger：`http://localhost:8080/swagger-ui.html`

## PC管理端启动

```bash
cd admin-web
npm install
npm run dev
```

默认访问：`http://localhost:5173`。

## 移动端H5启动

```bash
cd mobile-app
npm install
npm run dev:h5
```

默认访问：`http://localhost:5174`。

## 构建命令

```bash
cd backend
mvn clean compile
mvn test

cd ../admin-web
npm run build

cd ../mobile-app
npm run build:h5
```

## 常见问题

- 后端连接失败：确认 `localhost:8080` 后端已启动，MySQL连接正常。
- AI接口失败：确认 `AI_API_KEY`、模型权限、账户额度和网络可用。
- 地图白屏：确认 `VITE_AMAP_KEY` 和 `VITE_AMAP_SECURITY_JS_CODE` 已配置，Web端Key的域名白名单匹配当前访问地址。
- 图片404：确认后端 `uploads/` 目录存在，图片URL以 `/uploads/` 开头。
- RAG无来源：先在知识库导入演示文档或上传知识文档，并确认文档状态为“可用”。
