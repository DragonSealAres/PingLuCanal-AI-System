# 答辩演示流程

建议总时长：5到7分钟。

## 1. 项目背景和痛点，约1分钟

- 水上巡检依赖人工识别，隐患记录分散。
- 隐患处置链路长，审核、派单、处置、复核容易断点。
- 管理端需要实时掌握风险点位和处置进度。
- 航运业务问答需要知识来源可追溯。

一句话介绍：本系统通过AI视觉识别、智能工单闭环、AI复核、地图可视化和RAG知识问答，实现水上安全隐患智能巡检与闭环处置。

## 2. 完整业务演示，约3分钟

1. 移动端拍照上传巡检图片。
2. AI识别隐患类型、风险等级、描述和建议。
3. 巡检员确认并提交隐患。
4. PC后台刷新隐患列表，打开新隐患详情。
5. 管理员审核隐患。
6. 管理员创建工单，指派“处置人员01”。
7. 移动端打开“我的工单”，开始处理。
8. 上传处理后图片，填写处理说明并提交。
9. PC后台打开待复核工单，点击AI智能复核。
10. 管理员查看AI复核结果并最终审核完成。

## 3. 地图和Dashboard，约1分钟

- 打开“航道隐患一张图”。
- 展示高、中、低风险Marker颜色区分。
- 演示风险、状态、类型筛选。
- 打开Dashboard，展示隐患总数、今日新增、高风险、处理中、待复核、已完成、趋势图和高风险列表。

## 4. RAG问答，约1分钟

推荐问题：

- 发现航道漂浮物应该如何处理？
- 船舶过闸要注意什么？
- 高风险隐患怎么处理？
- 问一个知识库没有覆盖的问题，展示系统拒绝编造。

强调：回答带来源引用，便于答辩时说明不是凭空生成。

## 5. 技术架构和项目价值，约1分钟

- 前端：Vue3 PC管理后台、uni-app/H5移动端。
- 后端：Spring Boot 3、Java 17、MyBatis Plus。
- 数据库：MySQL。
- AI：千问多模态识别、图片复核、文本问答、Embedding。
- 地图：高德地图JS API。
- 价值：将隐患发现、审核、处置、复核、统计和知识服务串成可演示闭环。
