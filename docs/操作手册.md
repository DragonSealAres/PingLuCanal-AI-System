# 操作手册

## 巡检员

### 拍照上报

1. 打开移动端首页。
2. 进入“拍照上报”。
3. 选择或拍摄巡检图片。
4. 填写上报人、位置、经纬度。
5. 点击AI识别，等待系统返回隐患类型、风险等级、描述和处置建议。
6. 检查识别结果，确认后提交。

### 查看进度

1. 进入“我的上报”。
2. 查看隐患编号、风险等级、状态和上报时间。
3. 状态流转为：待审核、已审核、处理中、待复核、已完成。

## 管理员

### 审核隐患

1. 打开PC管理后台。
2. 进入“隐患管理”。
3. 打开待审核隐患详情。
4. 查看图片、AI识别结果、位置和描述。
5. 修正隐患类型、风险等级或描述后点击审核通过。

### 创建工单

1. 在已审核隐患详情中点击创建工单。
2. 填写工单标题、处置人员和处置要求。
3. 提交后工单状态为“待处理”，隐患状态进入“处理中”。

### 查看地图和Dashboard

1. 进入“航道隐患一张图”，查看隐患Marker。
2. 使用风险等级、状态、隐患类型筛选。
3. 点击Marker查看详情并跳转隐患详情。
4. 进入Dashboard查看隐患统计、风险分布、趋势和高风险列表。

### AI复核和最终完成

1. 打开待复核工单。
2. 点击AI智能复核，查看置信度、处理前后描述、剩余风险和AI建议。
3. 管理员确认后点击审核完成。
4. 工单和隐患状态变为“已完成”。

### 管理知识库

1. 进入“知识库管理”。
2. 上传TXT、Markdown或PDF文档。
3. 等待解析完成并确认状态为“可用”。
4. 可对文档执行重新解析或删除。

## 处置人员

### 接单处理

1. 打开移动端“我的工单”。
2. 找到分配给自己的工单。
3. 点击工单进入详情。
4. 点击“开始处理”。

### 提交处理结果

1. 在工单详情上传处理后照片。
2. 填写处理说明。
3. 点击提交。
4. 工单状态变为“待复核”，等待管理员审核。

## AI助手

1. 打开PC端或移动端AI助手。
2. 输入航运服务、隐患处置或业务流程问题。
3. 查看回答和参考来源。
4. 对知识库没有覆盖的问题，系统应提示暂无足够信息，避免编造。
