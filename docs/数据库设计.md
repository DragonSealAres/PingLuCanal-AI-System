# 数据库设计

## ER图

```mermaid
erDiagram
  hazard_report ||--o{ work_order : creates
  knowledge_document ||--o{ knowledge_chunk : splits
  chat_session ||--o{ chat_message : contains

  hazard_report {
    bigint id PK
    varchar report_no UK
    varchar report_user
    varchar location
    decimal longitude
    decimal latitude
    varchar image_url
    varchar hazard_type
    varchar risk_level
    text ai_result
    varchar status
    datetime create_time
    datetime update_time
  }

  work_order {
    bigint id PK
    varchar order_no UK
    bigint hazard_id
    varchar title
    varchar handler
    varchar requirement
    varchar status
    varchar handle_remark
    varchar handle_image
    datetime create_time
    datetime update_time
  }

  knowledge_document {
    bigint id PK
    varchar document_name
    varchar file_name
    varchar file_path
    varchar file_type
    varchar status
    int chunk_count
  }

  knowledge_chunk {
    bigint id PK
    bigint document_id
    int chunk_index
    text content
    longtext embedding
    varchar source_name
  }

  chat_session {
    bigint id PK
    varchar session_id UK
    varchar user_name
    varchar title
  }

  chat_message {
    bigint id PK
    varchar session_id
    varchar role
    text content
    text sources
  }
```

## 核心表说明

| 表名 | 用途 | 关键字段 |
| --- | --- | --- |
| `hazard_report` | 隐患上报与审核 | `report_no`、`hazard_type`、`risk_level`、`status`、`longitude`、`latitude` |
| `work_order` | 隐患处置工单闭环 | `order_no`、`hazard_id`、`handler`、`status`、`handle_image` |
| `knowledge_document` | RAG知识文档元数据 | `document_name`、`file_path`、`status`、`chunk_count` |
| `knowledge_chunk` | 知识切片与Embedding | `document_id`、`content`、`embedding`、`source_name` |
| `chat_session` | 多轮问答会话 | `session_id`、`user_name`、`title` |
| `chat_message` | 问答消息记录 | `session_id`、`role`、`content`、`sources` |

## 状态约定

隐患状态：`待审核 -> 已审核 -> 处理中 -> 待复核 -> 已完成`。

工单状态：`待处理 -> 处理中 -> 待复核 -> 已完成`。

退回处置可使用：`待复核 -> 处理中`。当前交付版本以前向闭环为主。
